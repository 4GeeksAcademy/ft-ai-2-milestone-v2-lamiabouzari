# Delivery Checklist Skill

## Objective

Validate the project before creating a Pull Request.

## Inputs

- Completed project
- Source code
- Memory Bank
- AGENTS.md

## Acceptance Criteria

- [ ] Project builds successfully.
- [ ] Lint passes without errors.
- [ ] Public website works correctly.
- [ ] Backoffice loads successfully.
- [ ] Shared business logic is reused.
- [ ] No duplicated business logic exists.
- [ ] Memory Bank is updated.
- [ ] Ready to open a Pull Request.
