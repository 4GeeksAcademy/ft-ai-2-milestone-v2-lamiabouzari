# Milestone 4 Rule

## Purpose

Ensure all changes follow the Maison Atelier Rue project architecture and preserve reusable business logic.

## Rules

- Always reuse code from `packages/shared` instead of duplicating business logic.
- Keep the public website and backoffice separated.
- Use TypeScript for all new code.
- Keep components small and reusable.
- Run `npm run lint` and `npm run build` before committing.
