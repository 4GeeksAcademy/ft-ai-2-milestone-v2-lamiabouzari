# Memory Bank Hygiene

Update `memory-bank/` when you make decisions that future sessions need:

| Event | Update |
|-------|--------|
| New app scaffolded | `architecture.md` — paths, scripts, key folders |
| Product/domain types added | `architecture.md` + note in `project-context.md` |
| Migration milestone completed | `project-context.md` — what is done vs. remaining |
| New safety constraint discovered | Add a new rule file in `memory-bank/rules/` |

Keep entries short and factual. Do not paste large code blocks into the memory bank.
