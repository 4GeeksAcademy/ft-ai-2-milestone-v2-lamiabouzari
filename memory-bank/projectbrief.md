# Project Brief

## Project

Maison Atelier Rue

## Overview

Maison Atelier Rue is a modern fashion and e-commerce company. This project migrates the existing collaborative application into the AI Engineering monorepo while preserving the website and preparing the project for future milestones.

## Goals

- Maintain the existing e-commerce website.
- Reuse shared business logic from previous milestones.
- Follow the AI Engineering monorepo structure.
- Prepare the project for backend, telemetry, agents, and workflow milestones.

## Current Status

- Public website migrated to Next.js.
- Shared package available.
- Memory Bank initialized.
- Project ready for continued development.
